# 错误码索引

| 码    | 类别     | 含义                |
|-------|----------|---------------------|
| E0100 | 名字解析 | 未定义变量          |
| E0101 | 名字解析 | 未定义函数          |
| E0102 | 名字解析 | 函数跨文件重名      |
| E0200 | 模块     | using 找不到文件    |
| E0201 | 模块     | using 循环引用      |
| E0301 | 可见性   | 调用私有函数        |
| E0308 | 类型     | 类型不匹配          |
| E0309 | 类型     | return 类型不符     |
| E0400 | 控制流   | 缺少 return         |
| E0401 | 控制流   | 条件必须 i64        |
| E0402 | 并发     | 嵌套 parallel for   |

用 `veloxc --explain <CODE>` 查看详情。

# E0202: 无法解析 C 头文件

`using "xxx.h"` 时，veloxc 调用 `clang -Xclang -ast-dump=json -fsyntax-only` 提取函数签名。这一步失败时抛 E0202。

## 常见原因

1. 系统没有 `clang`（macOS 请装 Xcode Command Line Tools）
2. 头文件本身有语法错误（clang 报错会附在消息里）
3. 头文件路径对不上（同 E0200 的路径规则：相对当前文件所在目录）

## 调试

手动跑一遍同样的命令：

```bash
clang -Xclang -ast-dump=json -fsyntax-only path/to/header.h | head
```

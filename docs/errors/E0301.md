# E0301: 调用私有函数

`foo` 声明为 `private`（或没写修饰符），只在**定义它的文件**内可见。

## 示例

```velox
// math.vx
fn helper(x: i64) -> i64 { return x + 1; }   // 默认 private
public fn square(x: i64) -> i64 { ... }
```

```velox
// main.vx
using "math.vx";
fn main() -> void {
  print(square(5));   // ✓
  print(helper(5));   // ✗ E0301
}
```

## 修法

- 需要跨文件用 → 加 `public`
- 只是本地辅助 → 保持 private，把使用逻辑挪进 math.vx

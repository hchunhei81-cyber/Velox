# E0301: 调用私有函数

`foo` 未使用 `pub` 声明（默认私有），因此只在**定义它的文件**内可见。

## 示例

```velox
// math.vx
fn helper(x: i64) -> i64 { return x + 1; }   // 默认 private
pub fn square(x: i64) -> i64 { ... }
```

```velox
// main.vx
using "math.vx";
fn main() -> void {
  print(square(5));   // ✓
  print(helper(5));   // ✗ E0301
}
```

## 修法

- 需要跨文件使用 → 加 `pub`
- 只是本地辅助 → 不写 `pub`，把使用逻辑留在 math.vx

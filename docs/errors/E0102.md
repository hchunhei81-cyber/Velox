# E0102: 函数跨文件重名

两个不同的 `.vx` 文件定义了同名函数。

## 原因

当前 `using` 是**文本内联**（类似 C 的 `#include`），没有命名空间隔离。

## 修法

1. 改名（推荐）
2. 把其中一个改成 `private`——但**不能**解决重名，只是语义更清晰
3. 等 Phase 2 的真实模块系统上线（届时会有 `math::square` 这样的路径）

## 示例

```
// a.vx
fn helper(x: i64) -> i64 { return x; }

// b.vx
fn helper(x: i64) -> i64 { return x + 1; }
```

同时 `using "a.vx"; using "b.vx";` → E0102。

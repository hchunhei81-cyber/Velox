# E0101: 未定义函数

调用了不在作用域内的函数名。

## 常见原因

1. 函数名拼错（检查大小写）。
2. 函数定义在其他文件但 `using` 写错。
3. 内置函数拼错（`printf` → `print`）。

## 内置函数

| 名字      | 签名            |
|-----------|-----------------|
| `print`   | `(i64) -> void` |
| `println` | `(str) -> void` |

## 示例

```velox
fn main() -> void {
  prnt(42);   // ✗ E0101
}
```
